# Frozen environment for FLUX.1-lite-8B on NxD Inference (Trn2)
#
# A `pip freeze` of a venv that runs everything in README.md and HANDSON.md on a
# trn2.3xlarge: text-to-image at tp_degree 2 and 4, the accuracy checks, and the
# pytest suite. Use it when you want the exact versions rather than "whatever pip
# resolves today" -- the compiler pin below is the one that matters most.
#
#   python3 -m venv ~/venv-nxdi-flux
#   ~/venv-nxdi-flux/bin/pip install -r contrib/models/flux.1-lite-8B/nxdi_requirements.txt \
#       --extra-index-url https://pip.repos.neuron.amazonaws.com
#   # then make *this repository* the NxDI that gets imported (see HANDSON.md 2.B):
#   ~/venv-nxdi-flux/bin/pip install -e . --no-deps
#
# Notes on three groups of lines below:
#
#   * neuronx-cc is pinned to 2.26.6360.0. 2.27 fails to compile FLUX on this stack
#     with `[NCC_ISMP902] Simplifier error: is_subset()`. Do not float it.
#   * libneuronxla / neuronx-cc / neuronx-distributed / nki / torch-neuronx /
#     torch-xla come from the Neuron index, hence --extra-index-url above.
#   * the nvidia-*-cu12 and triton wheels arrive with the PyPI torch build. They are
#     unused on Trainium; they are kept so the freeze stays faithful.
#
# neuronx-distributed-inference itself is deliberately *not* pinned here: it is this
# repository. The freeze recorded it as an editable git install, which would clone
# the repo a second time and pin an unrelated commit, so that line is commented out
# and replaced by the `pip install -e . --no-deps` step above.
#
# --extra-index-url https://pip.repos.neuron.amazonaws.com
